# mySLT Flutter App — Full Rebuild Implementation Plan

## Overview

The project at `d:\intern\myslt_app_2026` is a **blank Flutter project** (default counter app only, SDK ^3.10.7). We are building the **mySLT** app from scratch with clean architecture, modern UI, and the full feature set described in the spec.

The implementation is broken into **15 sequential phases**, each buildable and runnable in isolation. Code generation tools (Riverpod, Freezed, JSON serializable) will be run at appropriate milestones.

---

## User Review Required

> [!IMPORTANT]
> **Firebase Setup**: Firebase Auth (Email/Password, Google, Facebook) requires project-specific config files:
> - `google-services.json` → placed in `android/app/`
> - `GoogleService-Info.plist` → placed in `ios/Runner/`
>
> These files come from the Firebase Console and are **not generated by this plan**. Please confirm if you already have these files, or if Firebase integration should be **mocked/deferred** for the initial build.

> [!IMPORTANT]
> **Facebook Login App ID**: `flutter_facebook_auth` requires a Facebook App ID registered at developers.facebook.com. Confirm if this should be included or deferred.

> [!WARNING]
> **API Base URL**: The spec lists `https://api.myslt.lk/v1` as the base URL. Confirm this is the correct real endpoint, or if a different URL (e.g., local dev server) should be used in the `.env` file.

> [!NOTE]
> **Code Generation**: `riverpod_generator`, `freezed`, and `json_serializable` require running `dart run build_runner build`. This will be done at the end of Phases 1–5 before UI work begins.

#### [NEW] `lib/core/errors/exceptions.dart`

#### [NEW] `lib/core/utils/formatters.dart`
